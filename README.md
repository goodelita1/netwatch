# NetWatch — Мониторинг сети

## Установка

```bash
pip install flask
```

## Запуск

```bash
python app.py
```

Открыть в браузере: http://localhost:5000

## Функции

- ✅ Автоматический пинг всех устройств при запуске
- ✅ Кнопка ручного сканирования
- ✅ Зелёный/красный индикатор статуса
- ✅ Группировка по подсетям (88, 83, 21)
- ✅ Фильтры: все, онлайн, оффлайн, по типу
- ✅ Добавление новых устройств (кнопка + Добавить)
- ✅ Редактирование существующих устройств
- ✅ Удаление устройств
- ✅ Автообновление каждые 15 секунд
- ✅ Данные сохраняются в `devices.json`

## Типы устройств

- `router` — MikroTik роутер
- `ap` — WiFi точка доступа  
- `camera` — IP камера
- `client` — Клиентское устройство
- `mobile` — Мобильное устройство
- `server` — Сервер/VMware

## Добавление устройств

Нажать "+ Добавить устройство" в правом верхнем углу,
ввести IP, название, местоположение и тип.

Все устройства сохраняются в `devices.json` рядом с `app.py`.

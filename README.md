# ⬡ NetWatch — Мониторинг сетевой инфраструктуры

Веб-приложение на Python/Flask для мониторинга устройств в локальной сети.  
Без базы данных, без Docker — один файл `app.py`. Запускается за 10 секунд.

---

## Быстрый старт

```bash
pip install flask paramiko
python app.py
```

Открыть в браузере: **http://0.0.0.0:8000**

---

## Возможности

### ⚡ Индикатор питания (света)
Баннер в верхней части страницы — показывает есть ли электричество на предприятии:

| Состояние | Что показывает |
|-----------|---------------|
| 🟢 Зелёный | `192.168.88.1` отвечает → свет есть, пинг в мс |
| 🔴 Красный (пульсирует) | Шлюз не пингуется → вероятно отключение электроэнергии |
| ⚪ Серый | Ожидание первого пинга |

IP шлюза задаётся константой `POWER_IP = "192.168.88.1"` в начале `app.py`, либо меняется в ⚙️ Настройки.

---

### 📡 Мониторинг устройств
- Авто-пинг всех устройств каждые **60 секунд** в фоне
- Цветовая индикация статуса: зелёный / красный / серый
- **Спарклайн** — SVG-график латентности за последние ~2.4 часа прямо в ячейке «Пинг»
- Группировка устройств по подсетям
- Фильтрация: все / онлайн / оффлайн / роутеры / камеры / WiFi AP
- Сортировка по любому столбцу — клик по заголовку или выпадающий список

---

### 📋 Журнал событий
Вкладка «События» — полная история с фильтрами и временными метками.

| Тип события | Когда |
|-------------|-------|
| ⚡🔴 Свет отключён | Шлюз `192.168.88.1` перестал отвечать |
| ⚡🟢 Свет восстановлен | Шлюз снова онлайн (указывает сколько было отключено) |
| 🔴 Устройство упало | Любое устройство перестало пинговаться |
| 🟢 Устройство встало | Устройство снова онлайн |
| ⚠️ Долго недоступно | Недоступно дольше N минут (настраивается) |
| 🔄 Перезагрузка | Команда reboot отправлена успешно |
| 🆕 Новый хост | Авто-скан нашёл незарегистрированное устройство |

Хранится в `events.json`, последние 1000 записей. Автообновление каждые 30 секунд.

---

### 🤖 Telegram уведомления
Настраиваются в вкладке ⚙️ Настройки — без перезапуска.

**Что присылает:**
- ⚡ Отключение / восстановление света
- 🔴 Устройство недоступно дольше N минут
- 🆕 Новый незарегистрированный хост в сети

**Как настроить:**
1. `@BotFather` → `/newbot` → скопируйте токен
2. Добавьте бота в чат/канал, дайте права администратора
3. Узнайте Chat ID: `https://api.telegram.org/bot<TOKEN>/getUpdates`
4. Вставьте токен и Chat ID в ⚙️ Настройки → нажмите «Тест»

### 🔬 Глубокий скан
- MAC-адрес из ARP-таблицы
- Вендор по OUI (офлайн-база: MikroTik, Ubiquiti, Hikvision, ASUS, Apple, TP-Link, Cisco, VMware и др.)
- Модель по открытым портам (RouterOS, UniFi AP, IP Camera, NAS и др.)
- Прогресс-бар в реальном времени
- Результаты сохраняются в `devices.json`

---

### 🤖 Авто-сканирование сети

| Задача | Интервал | Что делает |
|--------|----------|------------|
| Авто-скан хостов | каждые **5 минут** | Пингует `.1–.254` всех зарегистрированных подсетей, находит незарегистрированные устройства |
| Авто-скан подсетей | каждые **15 минут** | Пингует шлюзы `192.168.0–255.1`, находит новые подсети |

Результаты — на главной странице, кнопки **+ Добавить** и **+ Реестр**.

---

### ⟳ Перезагрузка устройств

| Метод | Для кого |
|-------|---------|
| MikroTik REST API | RouterOS 7.x |
| MikroTik Binary API (порт 8728) | RouterOS 6.x |
| SSH via paramiko (`/system reboot`) | Все версии RouterOS |
| Hikvision ISAPI | IP-камеры Hikvision |
| Dahua HTTP CGI | IP-камеры Dahua |
| ASUS HTTP API | Роутеры ASUS |
| Generic HTTP | Неизвестные устройства |
| SSH generic (`reboot`) | Последний fallback |

## Файлы данных

| Файл | Содержимое |
|------|-----------|
| `devices.json` | Устройства: IP, имя, тип, вендор, MAC, учётные данные |
| `subnets.json` | Реестр подсетей |
| `events.json` | Журнал событий (последние 1000) |
| `telegram.json` | Настройки Telegram-уведомлений |

> ⚠️ Пароли устройств хранятся в открытом виде в `devices.json`. Не разворачивайте на публично доступном сервере без дополнительной защиты (nginx basic auth, firewall).

## Настройка

### IP шлюза для индикатора питания
```python
# app.py, строка 23
POWER_IP = "192.168.88.1"
```
Или через интерфейс: ⚙️ Настройки → «Индикатор питания».

### Интервалы авто-скана
```python
def background_auto_discovery():
    time.sleep(90)      # задержка при старте
    while True:
        ...
        time.sleep(300) # интервал в секундах (300 = 5 мин)

def background_auto_subnet():
    time.sleep(180)
    while True:
        ...
        time.sleep(900) # 900 = 15 мин
```

### Добавить вендора в OUI-базу
```python
# словарь OUI_DB в app.py
"XX:XX:XX": "VendorName",   # первые 3 октета MAC-адреса
```

## Запуск как сервис (Linux / systemd)

```ini
# /etc/systemd/system/netwatch.service
[Unit]
Description=NetWatch Network Monitor
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/netwatch
ExecStart=/usr/bin/python3 /opt/netwatch/app.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now netwatch
sudo journalctl -u netwatch -f   # логи
```
